# DESIGN GUIDELINES — NEGÓCIOS NO CHIVEVE

---

## 1. DESIGN PRINCIPLES

### 1.1 Clarity First
Content must be understood within seconds (mobile-first).

### 1.2 Accessible Authority
Professional, but never intimidating.

### 1.3 People-Centered
Human stories over abstract data.

### 1.4 Space = Value
More whitespace increases perceived quality.

### 1.5 Scanability
Users should grasp content without deep reading.

---

## 2. COLOR SYSTEM

### 2.1 Core Palette

| Type        | Color        | Usage |
|------------|-------------|------|
| Primary     | #1E4ED8     | Buttons, links, highlights |
| Background  | #FFFFFF     | Main background |
| Text        | #111111     | Primary text |
| Secondary   | #F5F5F5     | Section backgrounds |
| Neutral     | #9CA3AF     | Metadata, captions |

---

### 2.2 Usage Rules

- Use blue only for actions and highlights
- Avoid multiple strong colors on the same screen
- Keep visual hierarchy clean and intentional

---

## 3. TYPOGRAPHY

### 3.1 Font Pairing

- **Headlines:** Playfair Display / Merriweather (Serif)
- **Body:** Inter (Sans-serif)

---

### 3.2 Type Scale (Mobile-first)

| Element   | Size     | Weight     |
|----------|----------|-----------|
| H1       | 28–32px  | Bold      |
| H2       | 22–24px  | SemiBold  |
| H3       | 18–20px  | Medium    |
| Body     | 14–16px  | Regular   |
| Caption  | 12–13px  | Regular   |

---

### 3.3 Rules

- Maximum of 2 font families
- Use generous line-height (1.4–1.6)
- Avoid overusing bold text

---

## 4. GRID & SPACING

### 4.1 Mobile Grid

- Side margins: 16px
- Section spacing: 32–48px
- Element spacing: 12–16px

---

### 4.2 Spacing System (8pt)

- 4px
- 8px
- 16px
- 24px
- 32px
- 48px

---

## 5. CORE COMPONENTS

### 5.1 Article Card

**Structure:**
- Image (top)
- Category (small label)
- Title
- Reading time

**Rules:**
- Border radius: 8–12px
- No heavy shadows

---

### 5.2 Person Card

**Structure:**
- Profile image (face-focused)
- Name
- Title/role

**Note:**
This is a key differentiator component.

---

### 5.3 Buttons

#### Primary
- Blue background
- White text

#### Secondary
- Outline style (gray)

**Specs:**
- Height: 44–48px
- Border-radius: 8–12px

---

### 5.4 Tags (Categories)

- Light gray background
- Dark text
- Small and subtle

---

## 6. IMAGERY

### 6.1 Style

- Professional (LinkedIn-style)
- Clean backgrounds
- Well-lit portraits

---

### 6.2 Avoid

- Generic stock images
- Low-quality visuals
- Overly promotional imagery

---

### 6.3 Principle

Images must communicate credibility instantly.

---

## 7. LAYOUT & HIERARCHY

### 7.1 Content Order

1. Hero (featured content)
2. Key people (interviews/leaders)
3. Latest articles
4. Categories
5. Community

---

### 7.2 Layout Rules

- One dominant element per section
- Simple vertical flow
- Smooth scrolling experience

---

## 8. ADVERTISING

### Rules

- Placed between content blocks
- Non-intrusive
- Clearly labeled as "Sponsored"

---

## 9. NEWSLETTER

### Style

- Minimal
- Light background
- Strong headline

### Goal

Primary growth driver.

---

## 10. COMMUNITY

### Direction

- Emphasize belonging
- Emotional CTA

**Example:**
"Join the next generation of entrepreneurs"

---

## 11. VISUAL TONE

| Element   | Direction |
|----------|----------|
| Style     | Minimalist |
| Emotion   | Trust + Proximity |
| Language  | Simple, direct |
| Feel      | Modern editorial |

---

## 12. NON-NEGOTIABLE RULES

- No visual clutter
- No excessive color usage
- No complex layouts
- Always mobile-first
- Always people-focused
- Always scannable

---

- Editorial content
